RAG + LLM Static Analysis

GitHub Bug Detection & Recovery

Point it at a public repository. It scans the source, matches suspicious code against a knowledge base of historical bugs and fixes, then asks an LLM to explain what it found — and says so plainly when it isn't sure.

Works on any public GitHub repo. Private repos need auth this build doesn't set up.
Mini project build — bug type, location, severity, confidence and cause come from static analysis + LLM; historical matches come from BugsInPy / Bugs2Fix / RunBugRun via FAISS retrieval.
